Release checklist for cshape

1. Bump the version in pyproject.toml.
   Example: 0.2.2 -> 0.2.3

2. Clean old build artifacts.
   rm -rf dist build *.egg-info

3. Activate the virtual environment.
   source .venv/bin/activate

4. If .venv does not exist yet, create it once and install build tools.
   python3 -m venv .venv
   source .venv/bin/activate
   python3 -m pip install -U pip build twine

5. Build the package.
   python3 -m build

6. Upload the new version to PyPI.
   python3 -m twine upload -u __token__ dist/cshape-X.Y.Z*

7. When prompted, paste the PyPI token.
   The token must start with: pypi-

Notes:
- You cannot upload the same version twice. Every release must have a new version.
- Do not use a GitHub token that starts with ghp_. Twine upload to PyPI requires a PyPI token.
- Cleaning dist before build avoids uploading old files by mistake.
